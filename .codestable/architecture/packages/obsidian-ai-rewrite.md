# package:obsidian-ai-rewrite

代码：`packages/obsidian-ai-rewrite/`。面向 Obsidian Markdown 编辑器的插件，包内负责指令输入、图片读取、AI 流式请求、临时编辑器预览、差异确认和最终写回。业务词与约束由 [context:selection-rewrite](../../requirements/contexts/selection-rewrite.md) 定义。

## 边界与路径

- `manifest.json` 提供插件身份；`src/main.ts` 的 `AiRewritePlugin.onload` 注册命令、编辑器右键菜单、设置及文件切换处理，并管理单次会话从输入到确认的生命周期。
- `src/editor-views.ts` 关联 Obsidian 编辑器与 CodeMirror 视图；`src/selection-lock.ts` 的 `SelectionPreview` 集中开锁、预览缓冲、阶段切换、原文核对与应用；`selectionGuard`、`lockedRange` 负责范围保护，写回仍在锁模块内以单事务完成，`PreviewWidget` 渲染可折叠的思考与工具过程区，流式阶段提供可见的“取消生成”按钮，取消处理器按编辑器视图弱引用绑定、不进入编辑器状态；`appendThinking`、`setProgress`、`toggleProcess` 效果维护其中的思考内容、工具进度（每个调用一行，完成时原地更新）和展开状态，通过增量更新 DOM 保留滚动位置，过程区高度上限为 50vh，无新内容超过 8 秒时经 `quietHint` 显示等待文案；目标内容的保护规则见领域上下文。
- `src/prompt-modal.ts` 与 `src/images.ts` 接收指令和主动粘贴的图片；`src/context.ts` 的 `buildContext` 按字符额度截取选区（或光标）前后的原文，`currentStyleSample` 取当前笔记去掉选区后的正文（上限 8000 字）、`pickNeighborNotes` 按修改时间取同目录最近 3 篇笔记、`clipStyleSample` 截断每篇样本（1500 字）、`withStyleSamples` 把样本并进上下文；`src/web.ts` 的 `extractUrls` 从指令提取 http/https 链接并去重，`readWebPages` 经 Obsidian `requestUrl` 读取网页（非流式，绕过浏览器跨域限制），抽取标题与正文并按链接共享额度截断，读取失败直接抛错，由 `src/main.ts` 的 `submit` 统一取消并提示；`src/search.ts` 的 `WEB_SEARCH_TOOL` 提供 `web_search` 工具定义，`parseSearchArgs` 校验模型的 query/topic/timeRange，`searchWeb` 经 `requestUrl` 调用 Tavily `/search`（Bearer 密钥，非流式）；`src/files.ts` 的 `FILE_READ_TOOL` 提供只读的 `read_file`（path/offset/limit），`readLocalFile` 在函数开头用 `Platform.isDesktop`、`isDesktopApp` 和 `window.require` 把守后按需加载 `fs`/`path`/`os`（渲染进程的动态 import 解析不了 `node:` 模块，必须用 `window.require`；模块级不 import，手机版不加载文件系统），按 scope 校验路径、检测二进制并按行列额度截断；`src/ai.ts` 的 `streamRewrite` 根据设置和 `RewriteRuntime`（vaultRoot、desktop）决定挂载哪些工具，`SYSTEM_PROMPT` 要求延续风格样本的标题层级、列表与排版并禁止 `#` 一级标题，`CONCISE_PROMPT` 在「简洁」风格下追加密度与少装饰规则，样本以 `styleSamples` 随载荷发送；携带工具时在载荷里附带 `formatCurrentTime` 生成的当前时间，逐轮累积 `tool_calls` 与 `reasoning_content`（带 tools 的请求必须回传 reasoning），`runTool` 按名字派发搜索或文件读取，结果作为 tool 消息回填，最多 10 轮，额度用尽后不再带 tools 并插入一条系统提示让模型基于已有内容收敛作答，工具轮的中间文字由 `StreamSink.reset` 清出预览，思考与工具进度经 `StreamSink.reasoning`、`StreamSink.progress` 写进预览卡片（思考只保留最近 12000 字），单次请求超过 `STALL_TIMEOUT_MS`（120 秒）没有新数据会经 `stallPromise` 中断；`src/main.ts` 的 `submit` 用 `requestAnimationFrame` 按帧调度并保证至少间隔 `FLUSH_INTERVAL_MS`（80ms），由 `SelectionPreview.flush` 把思考与正文合并到一次事务；`src/selection-lock.ts` 的 `PreviewWidget` 用 `setTextData` 只改文本节点的 `data`（不重建节点，内容为纯文本，无高亮或 Markdown 解析）；`src/diff-modal.ts` 的 `DiffModal` 只有 `dismiss` 能关闭，背景点击、Esc 和关闭按钮都不会丢弃待确认结果；无工具时仍经浏览器 `fetch`请求配置的 Chat Completions 兼容接口并解析 SSE；`src/settings.ts` 保存接口、模型、上下文上限、写作风格（`stylePreset`）、风格参考范围（`styleScope`）、联网搜索开关与两套密钥（插件 `data.json` 为明文）。
- `src/inline-diff.ts` 的 `buildDiffRows` 用 `@codemirror/merge` 的 `presentableDiff` 求字符级改动，再把两侧行一一配对（纯插入/替换/删除分别按行尾、偏移、相对位置处理），输出 `context`、成对的 `removed`/`added` 与折叠行；`src/diff-view.ts` 的 `createDiffView` 按布局分派：`inline` 自行按行渲染（行号、`-`/`+` 标记、词级高亮、未改动折叠可展开），`split` 用 `MergeView` 挂载只读双栏；`src/diff-modal.ts` 用接近全屏的窗口展示它，工具栏切换内联/左右并在本次会话内保留选择，提供应用、复制与丢弃入口；显示结果不等于写回正文。
- 根 `scripts/install-obsidian-plugin.mjs` 安装包的 `main.js`、`manifest.json`、`styles.css`：先校验目标插件 ID 和版本、备份旧文件到根 `.tmp/`，失败时恢复已替换文件；不修改目标 `data.json`。
