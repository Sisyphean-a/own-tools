# AI Selection Rewrite（Obsidian 插件）

在 Markdown 编辑器中任意位置右键选择 **使用AI改写**，或运行命令 **用 AI 改写或生成内容**（可在快捷键设置中绑定）。有选区时改写选区；没有选区时在光标处生成。输入指令后可在输入框直接粘贴 JPEG、PNG、GIF 或 WebP 图片作为参考；缩略图可移除。按 Enter 提交并关闭输入框，Shift + Enter 换行，Esc 在提交前取消。

生成中的文字只在编辑器的临时预览卡片里流式显示，**不会写入笔记**。响应完成后出现词级差异对比（中英文混排可用）及 **应用改写/插入内容**、**复制结果**、**丢弃**。只有点击应用才一次性改动笔记，可用一次撤销恢复；关闭对比框或请求失败均保留原文。生成时可运行 **取消正在进行的 AI 改写**。大段文本超过 diff 预算时展示原文与结果并排对比，避免冻结界面。状态在生成结束时由“正在生成”转为“待确认”，应用或丢弃后清除。

提交时默认自动附带选区（或光标）前后的原文作为上下文，让模型理解语境：两侧共享一个字符额度，默认合计 4000 字，可在设置中改为 1000/2000/4000/8000/16000 字或关闭。超限时从远端截断，紧邻选区的内容一定保留；上下文分明，不会与选中文字重叠。

## 本地安装与升级

在仓库根先运行 `npm install`，然后运行 `npm run install:obsidian`：它会先构建，再将 `main.js`、`manifest.json`、`styles.css` 安装到当前系统用户的 `Documents/Obsidian Vault/.obsidian/plugins/obsidian-ai-rewrite/`，不写死用户名；不会修改 `data.json`。安装前在仓库 `.tmp/obsidian-plugin-backup/` 备份原有三个文件，失败时自动恢复。如果另一台电脑的笔记库路径不同，使用 `npm run install:obsidian -- --plugin-dir "完整插件目录"`；目标目录必须已存在且插件 ID 匹配。安装后在 **设置 → 第三方插件** 中重新加载或重新启用插件（必要时重启 Obsidian）。

首次安装默认使用 DeepSeek `https://api.deepseek.com/chat/completions`、`deepseek-flash`，需填写 DeepSeek API 密钥；兼容支持流式 SSE、图片内容块和跨域访问的其他 Chat Completions 接口。旧版的接口、模型、密钥不会自动迁移，若原来配置了其他服务，请自行确认当前设置。设置中的 **思考等级** 提供“服务默认 / 关闭 / 低 / 高 / 极高”：默认不传控制参数，原有配置不变；明确选档后才发送 Chat Completions 的 `reasoning_effort`（分别为 `none / low / high / max`）。DeepSeek 默认启用高强度思考；极高可能延长响应并增加费用，其他服务需自行支持该字段，否则请求会报错。模型的 `reasoning_content` 不显示、不写入笔记；参考 [DeepSeek 思考模式文档](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode)。提交时只将指令、所选文字、选区前后受上限约束的上下文及**主动粘贴的图片**发送到配置的服务；不会发送全文或文件名。图片仅保存在本次对话内存，不写入笔记库；每张上限 32 MiB，请求体上限 48 MiB（DeepSeek 的限制）。其他模型可能不支持图片，错误会直接提示，不会悄悄丢弃图片。

密钥保存在插件 `data.json`，为**明文且可能被笔记库同步**；请勿分享，泄漏后应轮换。锁定仅拦截本编辑器中的普通事务，不阻止其他插件、外部同步或磁盘编辑；应用前会核对文件与选区内容，防止覆盖不相关修改。若内容变化，对比框仍可复制结果，不会强行应用。

差异算法借鉴本地参考项目 `ai-refiner-master` 的词级 LCS 预览思路，改为支持中文分词、空选区插入和独立于实际写回的编辑器内预览；未复制其 UI 工作流。参考项目采用 0-BSD 许可证。

## 开发

在仓库根运行 `npm test`、`npm run lint`、`npm run build`。未内置快捷键，避免与现有快捷键冲突。
