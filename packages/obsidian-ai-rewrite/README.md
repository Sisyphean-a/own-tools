# AI Selection Rewrite（Obsidian 插件）

在 Markdown 编辑器中任意位置右键选择 **使用AI改写**，或运行命令 **用 AI 改写或生成内容**（可在快捷键设置中绑定）。有选区时改写选区；没有选区时在光标处生成。输入指令后可在输入框直接粘贴 JPEG、PNG、GIF 或 WebP 图片作为参考；缩略图可移除。按 Enter 提交并关闭输入框，Shift + Enter 换行，Esc 在提交前取消。

生成中的文字只在编辑器的临时预览卡片里流式显示，**不会写入笔记**。卡片顶部是可折叠的「思考与工具」过程区：实时显示模型的思考内容，以及链接读取和联网检索的进度（每次调用与结果占一行，完成时原地更新），并计时；超过 8 秒没有新内容时显示“仍在等待…”提示，避免看起来像卡死，长时间等待时也能看出请求仍在推进；过程区最高为窗口高度的一半，超出时内部滚动，且只显示在卡片里，不会写入笔记。响应完成后打开确认框，窗口默认占屏幕的 94% 宽、88% 高：可在 **内联**（按行对齐的统一差异：同一行的改动成对显示 `-`/`+`，左侧是原文行号、右侧是结果行号，未改动区域自动折叠并可点击展开）与 **左右**（原文与结果并排逐行对照，上方标注“原文/AI 结果”）两种差异视图间切换，选择在本次会话内保留；改动词用主题色高亮，删除部分带删除线；底部提供 **应用改写/插入内容**、**继续修改**、**复制结果**、**丢弃**。只有点击应用才一次性改动笔记，可用一次撤销恢复；确认框只能通过“应用/丢弃”离开，点外部空白、按 Esc 或右上角关闭都不会丢弃结果；请求失败会保留原文，并自动回到输入框、保留已输入的指令与图片，可直接修改后重试。流式连接超过 **120 秒**没有任何新内容会自动中断并提示重试（避免服务端挂死时无限等待）；过程区最多保留最近约 12000 字的思考内容，高频输出会合并渲染，长时间生成不再拖慢编辑器。生成时可点击预览卡片中的 **取消生成**，也可运行命令 **取消正在进行的 AI 改写**。超大文本超过差异计算的等待上限时会回退到不精确对比，确认框不会卡住。状态在生成结束时由“正在生成”转为“待确认”，应用或丢弃后清除。

应用后仍可继续调整。确认框里的 **继续修改** 不写回笔记，直接回到输入框并预填上一轮要求；点 **应用改写** 写入后，插件会记住这段结果和对话历史，点击应用提示，或在右键菜单、命令面板运行 **继续修改上一次 AI 结果**，就会重新选中刚写入的内容继续生成。历史按真实对话发送（每轮的要求与已应用结果，最多 5 轮、合计 16000 字），模型能看到上一版的样子和你的改法；只记录已应用到笔记的版本。结果被手动改动或切换文件后，继续入口会失效，不会覆盖你的修改；上一轮的图片不会自动重发，需要时重新粘贴。

提交时默认自动附带选区（或光标）前后的原文作为上下文，让模型理解语境：两侧共享一个字符额度，默认合计 4000 字，可在设置中改为 1000/2000/4000/8000/16000 字或关闭。超限时从远端截断，紧邻选区的内容一定保留；上下文分明，不会与选中文字重叠。

设置中可选择 **写作风格**：默认的「简洁」要求信息密度优先、短句、少用加粗/斜体/引用块/分隔线/emoji 和大表格；「宽松」只要求延续笔记已有形态。生成新内容时不产出 `#` 一级标题（大标题由你自己维护），需要分节时只用 `##` 及以下；改写已有内容时保留原层级。

**风格参考**默认把当前笔记去掉选区后的正文（最多 8000 字）作为形态样本发送，模型先看已有标题层级、列表符号与编号、缩进、行内代码、术语与标点，再按同样形态输出；新建文档时可改为「当前笔记 + 同目录」，附带同目录最近 3 篇笔记的开头（每篇最多 1500 字）；也可以关闭。样本只学形态，不复述内容。

指令中可以直接包含链接（最多 3 个）：提交时先用 Obsidian 网络请求读取网页正文，去掉脚本、导航等噪声后随指令一起交给模型，因此可以直接让 AI 总结链接内容或就链接提问。多个链接均分合计约 16000 字的正文额度，超出按段落截断并以 `…` 标注；Markdown 链接 `[标题](url)`、尖括号链接和中文标点连写都能识别。链接读取失败（网络错误、HTTP 4xx/5xx、非网页文本、正文为空）会明确提示并保留原文，不会静默忽略；读取期间显示常驻提示，可随时取消。

设置中可开启 **联网搜索**（需填写 Tavily API 密钥，默认接口 `https://api.tavily.com/search`）：开启后每次提交都会附带 `web_search` 工具，由模型自行判断是否需要检索——问新闻、最新进展或需要事实核查时会先搜索网页再作答，并附上来源链接；普通改写不会触发。搜索主题（常规/新闻/财经）和时间范围（一天/一周/一月/一年）由模型按问题选择；开启工具时每次请求都会附带当前时间（含星期与时区），避免模型沿用训练数据里的日期。搜索失败（网络、HTTP 错误、无效数据）会明确提示并保留原文；一次请求最多 10 轮检索，用尽后模型会停止检索、基于已有资料作答，而不是把失败抛给用户。开启前请确认所配置的 Chat Completions 接口支持工具调用（function calling），否则请求会报错。

设置中还可开启 **文件读取**（默认关闭，仅桌面版）：开启后模型可调用只读的 `read_file` 工具读取你给出的本地路径——绝对路径、`~/` 开头或笔记库相对路径都支持。范围可选 **仅笔记库**（库外路径明确拒绝）或 **允许任意本地路径**；单次默认读 2000 行（上限 5000 行、约 120 KB），超出时返回截断说明和续读位置，模型可用 `offset` 继续读。它没有写入或修改能力；文件不存在、是目录、无权限、二进制或编码无法识别都会明确提示，文件内容会随请求发送给所配置的 AI 服务。

## 本地安装与升级

在仓库根先运行 `npm install`，然后运行 `npm run install:obsidian`：它会先构建，再将 `main.js`、`manifest.json`、`styles.css` 安装到当前系统用户的 `Documents/Obsidian Vault/.obsidian/plugins/obsidian-ai-rewrite/`，不写死用户名；不会修改 `data.json`。安装前在仓库 `.tmp/obsidian-plugin-backup/` 备份原有三个文件，失败时自动恢复。如果另一台电脑的笔记库路径不同，使用 `npm run install:obsidian -- --plugin-dir "完整插件目录"`；目标目录必须已存在且插件 ID 匹配。安装后在 **设置 → 第三方插件** 中重新加载或重新启用插件（必要时重启 Obsidian）。

首次安装默认使用 DeepSeek `https://api.deepseek.com/chat/completions`、`deepseek-flash`，需填写 DeepSeek API 密钥；兼容支持流式 SSE、图片内容块和跨域访问的其他 Chat Completions 接口。旧版的接口、模型、密钥不会自动迁移，若原来配置了其他服务，请自行确认当前设置。设置中的 **思考等级** 提供“服务默认 / 关闭 / 低 / 高 / 极高”：默认不传控制参数，原有配置不变；明确选档后才发送 Chat Completions 的 `reasoning_effort`（分别为 `none / low / high / max`）。DeepSeek 默认启用高强度思考；极高可能延长响应并增加费用，其他服务需自行支持该字段，否则请求会报错。模型的 `reasoning_content` 不显示、不写入笔记；参考 [DeepSeek 思考模式文档](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode)。提交时只将指令、所选文字、选区前后受上限约束的上下文、**风格样本**、**主动粘贴的图片**及**指令中链接的网页正文**发送到配置的服务；开启联网搜索时，模型还会把查询词发送给搜索服务并把检索结果随请求交给模型。不会发送文件名。图片仅保存在本次对话内存，不写入笔记库；每张上限 32 MiB，请求体上限 48 MiB（DeepSeek 的限制）。其他模型可能不支持图片，错误会直接提示，不会悄悄丢弃图片。

密钥保存在插件 `data.json`，为**明文且可能被笔记库同步**；请勿分享，泄漏后应轮换。锁定仅拦截本编辑器中的普通事务，不阻止其他插件、外部同步或磁盘编辑；应用前会核对文件与选区内容，防止覆盖不相关修改。若内容变化，对比框仍可复制结果，不会强行应用。

差异计算与左右视图由 CodeMirror 的 `@codemirror/merge` 提供（MIT 许可）：左右视图用它自带的合并视图，内联视图用它算出的字符级改动自行按行配对渲染。

## 开发

在仓库根运行 `npm test`、`npm run lint`、`npm run build`。未内置快捷键，避免与现有快捷键冲突。
